# 領収書アプリ

その場で領収書を作って、**LINE やメールで送れる画像（PNG）か PDF** にするアプリです。
パソコンでも携帯でも、ブラウザで開くだけで使えます。

- URL：`https://（ユーザー名）.github.io/collagen-inventory/ryoshusho/`
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（方法は上のフォルダの README と同じです）

## 使い方

1. 「🧾 作成」で発行元（シナリーくらげ営業所 / kagmian）を選ぶ
2. 発行日・但し書き・明細（品名・数量・税込の単価・税率）を入れる
   - **宛名はふだん空欄** のままで大丈夫です（領収書には手書き用の線と「様」だけ出ます）
   - 食品（コラーゲンドリンクなど）は **8%**、化粧品・施術などは **10%** を選びます
3. 下の「できあがり」で見た目を確認
4. 形式を選ぶ：**基本は画像（PNG）**。PDF がほしいときだけ切り替えます
5. 「📤 LINE・メールで送る」→ 共有の画面で LINE かメールを選ぶ
   （パソコンなど共有ができないときは、ファイルが保存されるのでメールに添付してください）

### 🔒 自分用メモ（領収書には出ません）
作成画面の「自分用メモ」に、次のことを書いておけます。

- **お客様の名前**（宛名は空欄のままでも、自分の記録用に名前を残せます。前に入れた名前は候補に出ます）
- **渡した日**（カレンダーで選べます。発行日とは別に記録できます）
- **渡した場所**
- **現金を受け取った場所**

紙で渡したときなど、送らずに記録だけしたいときは「📚 送らずに履歴にだけ残す」を押します。
あとからメモを直すときは、履歴から「開く・直す」→ メモを書き直して「💾 メモを保存」。

### 📚 履歴（渡した人の一覧と金額）
- **月ごと**（渡した日で分けます）に、合計金額・枚数・人数を表示。◀ ▶ で月を移動、「すべて」でこれまでの全部
- **お客様ごとの合計**（枚数・金額）。名前を押すと、その人の領収書だけに絞り込み
- 名前や場所で検索
- 1枚ずつのカードに、渡した日・金額・渡した場所・現金を受け取った場所を表示

送ったり保存したりした領収書には **番号（No.0001〜）** が付いて「📚 履歴」に残ります。
履歴から開けば同じ番号のまま送り直し・修正ができ、「複製して新しく」で同じ内容の新しい領収書も作れます。

## 領収書に出る内容（インボイス対応）

| 項目 | 内容 |
|---|---|
| 発行元 | 名前（屋号）・〒922-0134 石川県加賀市山中温泉荒谷町ヌ116・TEL 080-5093-2579 |
| 登録番号 | T5810440696021 |
| 日付・番号 | 発行日と通し番号 |
| 金額 | 税込の合計 |
| 但し書き・明細 | 品名・数量・単価・金額（8% の品には ※ 印） |
| 税率ごとの内訳 | 10%対象・8%対象の金額と、それぞれの消費税額（税率ごとに合計して1回だけ計算、1円未満切り捨て） |

発行元の名前・住所・電話・登録番号は「⚙️ 設定」で変えられます。発行元を足すこともできます。

## 注意

- 履歴はこの端末のブラウザの中だけに保存されます（インターネットには送られません）。
  機種変更やブラウザのデータ消去で消えるので、ときどき「履歴」画面から CSV を書き出してください。
- 画像・PDF で送る領収書（電子の領収書）には **収入印紙はいりません**。
  紙に印刷して手渡しする場合、5万円以上なら収入印紙が必要です。
