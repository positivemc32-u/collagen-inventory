# 体験会の精算アプリ

化粧品の体験会（3人で運営）の **売上・材料の返金・駐車場代の返金・経費** をまとめて計算し、**残高** をその場で出すアプリです。
パソコンでも携帯でも、ブラウザで開くだけで使えます。

- URL：`https://（ユーザー名）.github.io/collagen-inventory/taikenkai/`
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（方法は上のフォルダの README と同じです）

## 計算のしかた

```
残高 ＝ 売上 − 駐車場代の返金 − 材料の返金 − 経費
```

| 項目 | 内容 |
|---|---|
| 売上 | 参加者ごとに体験メニューを選ぶと自動で合計（チラシの料金を登録済み） |
| 駐車場代の返金 | 2,000円以上で100円、3,000円以上で300円を自動で選びます（手で変更もできます） |
| 材料の返金 | 材料ごとの **使用人数** は、参加者が選んだ体験メニューから自動で数えます（例：アロマ占いだけの人は数えない。違うときは −／＋ で直せます）。単価×人数×返金の割合（**倉は50％、ほかの人は80％**。1円未満は四捨五入）を返金。ふだんは「倉の物だけ」、ほかの人も出したときは「倉・新谷・田中で分ける」（人数の半分を倉、残りの半分を新谷・田中で割る）。「人ごとに入力」で自由に分けることもできます |
| 例 | 基礎化粧品689円を4人が使い「倉・新谷・田中で分ける」→ 倉 2人分×689円×50％＝689円、新谷・田中 各1人分×689円×80％＝551円 |
| 経費 | 場所代など。「立て替えた人」を選ぶと、その人への返金に足されます |

### 材料の単価（一回分）
「単価計算」Excel の合計から登録しています。

| 材料 | 単価 |
|---|---|
| 基礎化粧品 一回分 | 689円 |
| 新基礎化粧品 一回分 | 719円 |
| 美容液 一回分 | 561円 |
| 【下地ファンデーション一回分】 | 436円 |
| 【トップメイク一回分】 | 410円 |
| パルファン 1人分 | 10円 |
| アロマパック 1回分 | 100円 |
| 美肌クレイパック 1回分 | 400円 |
| タラソパック 1回分 | 500円 |
| ジンセントニック 1回分（ヘッドケア） | 72円（5,720円・80回分） |
| RB 1回分（ヘッドケア） | 141円（8,470円・60回分） |
| ミルキーアイドル 1回分（ハンドケア） | 407円（4,070円・10回分） |

返金の割合は「⚙️ 設定」の「材料を出す人と返金の割合」で変えられます。設定の材料の一覧には、割合をかけた1回分の原材料費（例：ジンセントニック 倉36円／ほか58円）も表示されます。

### どのメニューでどの材料を数えるか
「⚙️ 設定」の「体験メニューと料金」で、メニューごとにチェックで変えられます。最初の設定は次のとおりです。

| メニュー | 数える材料 |
|---|---|
| スキンケア＆メイク体験（アロマパック付き）※小中高生も | 基礎化粧品・美容液・下地ファンデーション・トップメイク・パルファン・アロマパック |
| スキンケア体験 ※小中高生も／美容体験 | 基礎化粧品・美容液・パルファン |
| ナチュラルメイク体験 ※小中高生も | 下地ファンデーション・トップメイク・パルファン |
| オプション：アロマパック／美肌クレイパック／タラソパック | それぞれのパック |
| セルフヘッドケア | ジンセントニック・RB |
| ハンドケア | ミルキーアイドル |
| アロマ占い・口腔ケア・潤いシートパック | 数えない |

単価・材料・人・メニュー・経費の項目は「⚙️ 設定」でいつでも変更・追加できます。
変更しても **過去の会の金額は変わりません**（会ごとに作成時の単価を記録しています）。
その会だけ単価を変えたいときは、精算画面の「材料・単価・返金の割合をこの会だけ変更」を使ってください。

## 使い方

1. **📅 会の一覧** →「＋ 新しい会を作る」：日付（カレンダーから選べます。曜日も表示）・会の名前・種類（体験会／その他の会）・会場を入れる
   - 前回の経費（場所代など）を引き継ぐこともできます
2. **🧾 精算**：
   - ① 参加者を追加して、体験メニューにチェック
   - ② 材料の使用人数は参加者のメニューから自動で入ります。誰の物を使ったか（倉の物だけ／倉・新谷・田中で分ける／人ごとに入力）を選ぶ
   - ③ 経費のボタン（＋場所代 など）を押して金額を入れる
   - 上に出ている **残高** が入力のたびに計算し直されます
   - ④ 精算結果に「誰にいくら返すか」が出ます
3. **📊 集計**：会ごと・年ごとの残高、累計、人ごとの返金合計

## データについて（大事）

- データは **その端末のブラウザの中だけ** に保存されます。インターネットには送られません。
- パソコンと携帯、3人の間で同じデータを使うときは、**💾 バックアップ** の「書き出す」でできたファイルを
  LINE やメールで送り、もう片方の端末で「読み込む」してください（読み込むとその端末のデータは置き換わります）。
- Excel で見たいときは「CSV を書き出す」を使ってください。
