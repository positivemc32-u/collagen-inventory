# 体験会の精算アプリ

化粧品の体験会（3人で運営）の **売上・材料の返金・駐車場代の返金・経費** をまとめて計算し、**残高** をその場で出すアプリです。
パソコンでも携帯でも、ブラウザで開くだけで使えます。

- URL：`https://（ユーザー名）.github.io/collagen-inventory/taikenkai/`
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（方法は上のフォルダの README と同じです）

## 計算のしかた

```
残高 ＝ 売上 − 駐車場代の返金 − 材料の返金 − 経費
```

| 項目 | 内容 |
|---|---|
| 売上 | 参加者ごとに体験メニューを選ぶと自動で合計（チラシの料金を登録済み） |
| 駐車場代の返金 | 2,000円以上で100円、3,000円以上で300円を自動で選びます（手で変更もできます） |
| 材料の返金 | 材料ごとに「倉／新谷由起美AD／田中博明AD／その他」の誰が出したかと回数を入れると、単価×回数をその人に返金 |
| 経費 | 場所代など。「立て替えた人」を選ぶと、その人への返金に足されます |

### 材料の単価（一回分）
「単価計算」Excel の合計から登録しています。

| 材料 | 単価 |
|---|---|
| 基礎化粧品 一回分 | 689円 |
| 新基礎化粧品 一回分 | 719円 |
| 美容液 一回分 | 561円 |
| 【下地ファンデーション一回分】 | 436円 |
| 【トップメイク一回分】 | 410円 |
| パルファン 1回分（10プッシュ） | 40円 |

単価・材料・人・メニュー・経費の項目は「⚙️ 設定」でいつでも変更・追加できます。
変更しても **過去の会の金額は変わりません**（会ごとに作成時の単価を記録しています）。
その会だけ単価を変えたいときは、精算画面の「材料・単価をこの会だけ変更」を使ってください。

## 使い方

1. **📅 会の一覧** →「＋ 新しい会を作る」：日付・会の名前・種類（体験会／その他の会）・会場を入れる
   - 前回の経費（場所代など）を引き継ぐこともできます
2. **🧾 精算**：
   - ① 参加者を追加して、体験メニューにチェック
   - ② 材料を出した人の欄で −／＋ を押して回数を入れる
   - ③ 経費のボタン（＋場所代 など）を押して金額を入れる
   - 上に出ている **残高** が入力のたびに計算し直されます
   - ④ 精算結果に「誰にいくら返すか」が出ます
3. **📊 集計**：会ごと・年ごとの残高、累計、人ごとの返金合計

## データについて（大事）

- データは **その端末のブラウザの中だけ** に保存されます。インターネットには送られません。
- パソコンと携帯、3人の間で同じデータを使うときは、**💾 バックアップ** の「書き出す」でできたファイルを
  LINE やメールで送り、もう片方の端末で「読み込む」してください（読み込むとその端末のデータは置き換わります）。
- Excel で見たいときは「CSV を書き出す」を使ってください。
