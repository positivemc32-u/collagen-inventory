# Notionメモ（iPhone から Notion に文字・音声で入れるアプリ）

- URL：<https://positivemc32-u.github.io/collagen-inventory/notion/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」するとアプリのように使えます。

## できること

| 機能 | 内容 |
|---|---|
| ⌨️ 文字で入力 | タイトル（空なら1行目）と本文を書いて「Notion に送る」 |
| 🎤 音声で入力 | 🎤 を押して話すと本文に文字が入ります。もう一度押すと止まります。ボタンが使えないときはキーボードのマイク 🎙 で話してもOK |
| 📚 送り先 | Notion の **データベース**（1メモ＝1行）か **ページ**（中に子ページとして追加）。データベースなら日付・タグの列にも入れられます |
| 🕘 送ったもの | 送った記録。「もう一度送る」「直して送る」ができます |
| 💾 下書き | 書きかけは自動で残ります |

## しくみ（なぜ「ショートカット」を使うのか）

Notion はブラウザ（Webページ）から直接書き込むことを受け付けていません。
そこで、このアプリで書いた内容を iPhone の **「ショートカット」アプリ** に渡し、ショートカットが Notion に保存します。
サーバーは不要で、お金もかかりません。

- Notion の鍵（シークレット）は **ショートカットの中だけ** に入れます。このアプリや GitHub には入りません。
- 下書き・送った記録・送り先のリンクは、この iPhone のブラウザの中だけに保存されます。

## はじめの準備（1回だけ・10分ほど）

### 1. Notion の「コネクト」（鍵）を作る
1. <https://www.notion.so/profile/integrations> を開く（いつもの Notion のアカウントでログイン）
   → 「開発者ツール」の「コネクション」画面が開きます
2. 右上「＋ 新規コネクト」→ コネクト名「メモ送信」、認証方法は **「APIトークン」** のまま →「コネクトを作成」
3. 出てきたトークン（`ntn_` で始まる文字）をコピー
   **この文字は人に見せないでください。**

### 2. 送り先を用意してつなぐ
1. Notion でメモを入れたいページ（またはデータベース）を開く
   - おすすめ：新しいページで `/データベース` → 「データベース：フルページ」を作り「メモ箱」などと名前を付ける
2. 右上の「…」→「接続」（または「コネクト」）→ さっき作った「メモ送信」を追加（コネクト作成後の画面の「アクセス」から、ページを選んで許可することもできます）
3. 右上の「…」→「リンクをコピー」

### 3. このアプリの設定
1. アプリを開くと ⚙️ 設定が出るので、「送り先のリンク」にコピーしたリンクを貼る
2. 種類を「データベース」か「ページ」から選ぶ（データベースのリンクは自動で判定されます）
3. データベースの場合、タイトル列の名前を確認（日本語の Notion ならふつうは「名前」）
   日付の列・タグ（マルチセレクト）の列があれば、その名前も入れられます（任意）

### 4. iPhone の「ショートカット」アプリで送信用ショートカットを作る
1. 「ショートカット」アプリ → 右上の ＋
2. 一番上の名前を **「Notionに送る」** にする（アプリの設定と同じ名前にします）
3. 「アクションを追加」→ 検索で **「URLの内容を取得」** を追加し、次のように設定：
   - URL：`https://api.notion.com/v1/pages`
   - 「＞」を開いて **方法**：`POST`
   - **ヘッダ** を3つ追加

     | キー | 値 |
     |---|---|
     | `Authorization` | `Bearer ntn_xxxxxxxx`（1でコピーした文字。Bearer のあとに半角スペース） |
     | `Notion-Version` | `2022-06-28` |
     | `Content-Type` | `application/json` |
   - **本文を要求**：「ファイル」を選び、ファイルの欄で「ショートカットの入力」を選ぶ
   - **ヘッダのキーと値は、🌐で英語キーボードに切り替えて手で打つのがおすすめ**です。
     貼り付けや日本語キーボードの「空白」だと、見えないスペース（全角スペース・改行）が入ってエラーになることがあります。
4. （おすすめ）下に **「通知を表示」** を追加し「Notion に送りました」と入れる
   - うまくいかないときは、代わりに **「コンテンツを表示」** を追加すると、Notion からの返事（エラーの内容）が見られます
5. 完了

### 5. テスト
アプリの ⚙️ 設定 →「🧪 テストで送ってみる」。Notion に「テスト（Notionメモ）」が入れば完成です。
初めてのときは「Notion に接続することを許可しますか？」と聞かれるので「常に許可」を押してください。

## うまくいかないとき

| こうなる | 直し方 |
|---|---|
| 401 で「must use the format Bearer <token>」 | Authorization の値に余計なスペース・改行が入っています。行を消して、英語キーボードで `Bearer ` と打ち、トークンを貼り直す |
| 400 で「missing_version」 | `Notion-Version` のキーに余計な文字が入っています。行を消して、英語キーボードで打ち直す |
| 「ショートカットが見つかりません」 | ショートカットの名前とアプリの設定の名前を同じにする |
| 401 / unauthorized | `Authorization` の値が `Bearer ` ＋ シークレットになっているか（スペースも） |
| 404 / object_not_found | 送り先のページに「接続」でインテグレーションを追加したか。リンクが合っているか |
| 400 / validation_error（〇〇 is not a property） | 設定の「タイトル列の名前」「日付・タグの列の名前」が Notion の列名と同じか。種類（データベース／ページ）が合っているか |
| 🎤 ボタンが反応しない | iPhone の設定 → Safari → マイク を「許可」に。だめならキーボードのマイク 🎙 で話してください |
| 送ったあと Safari が開く | 設定の「送ったあと、このページに戻ってくる」をオフに（ホーム画面から使うときはオフがおすすめ） |
