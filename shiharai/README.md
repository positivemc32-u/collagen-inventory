# 毎月の支払いアプリ

毎月の支払いの日程と、どの銀行から引き落とされるかをまとめて、
**通帳にある金額を入れると、足りるか・いくら入金が必要か（差額）** がすぐわかるアプリです。
携帯でもパソコンでも、ブラウザで開くだけで使えます。

- URL：`https://（ユーザー名）.github.io/collagen-inventory/shiharai/`
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（方法は上のフォルダの README と同じです）

## はじめに（一度だけ）

最初は銀行・カードは空っぽです。「⚙️ 設定」で、使っている **銀行（口座）・カード・毎月の支払い** を入れてください。
入れた内容は **この端末のブラウザの中だけ** に保存されます（GitHub やインターネットには載りません）。
毎月の支払いのひな形には、はじめ「27日 家賃」「27日 カード決済」だけが入っています。

> ⚠️ 家族の名前・銀行名などの個人情報は、プログラム（data.js など）には書かず、必ずアプリの「⚙️ 設定」で入れてください。プログラムは GitHub で公開されています。

銀行・カードは、選ぶ欄の一番下の **「＋ 銀行を追加…」「＋ カードを追加…」** からその場で足せます。
名前の変更・削除、毎月の支払い（ひな形）の追加・変更は「⚙️ 設定」でできます。

## 使い方

### 📅 予定
1. 上の ◀ ▶ で月を選ぶ（初めて開いた月は、毎月の支払いから自動で予定ができます）
2. それぞれの支払いに **金額** と **引き落とし口座** を入れる
   - 金額は前の月に入れた金額を引き継ぐので、家賃など毎月同じものは入れ直さなくて大丈夫です
   - カードは「⚙️ 設定」で引き落とし口座を決めておくと、口座が自動で入ります
   - 引き落とし日が土日のときは「土日 → 翌月曜」と表示します（祝日は通帳で確認してください）
3. 引き落とされたら「⬜ まだ」を押して **「✅ 済」** にする
4. その月だけの支払いは「＋ 支払いを足す」で追加できます

### 💳 前月からのキャッシング
- 「📅 予定」の下の **「この月にキャッシングした分」** にカードと金額を記録しておくと、
  **次の月を開いたときに「前月からのキャッシング」として自動で入ります**（27日のカード引き落としと一緒）
- 初めて使う月は「＋ 前月からのキャッシング」で手で入れてください

### 🏦 通帳・差額
口座ごとに **通帳にある金額** と **入金する額** を入れると、

> **差額 ＝ 通帳にある金額 ＋ 入金する額 − まだの支払い**

が出ます。足りない口座は赤くなり「あと ¥○○ 入金が必要です」と表示されます。
「不足分を『入金する額』に足す」を押すと、必要な入金額が入ります。
日にち順に、引き落とし後に残る金額も表示します。
「✅ 済」にした支払いは、もう通帳から引かれている分として数えません。

## データの保存について
- データは **この携帯（ブラウザ）の中だけ** に保存されます。GitHub やインターネットには送られません。
- 別の携帯やブラウザでは見えません。ブラウザのデータを消すと消えます。
- 「💾 バックアップ」で、ときどきバックアップを保存してください。
  - 「📥 バックアップをこの端末に保存」または「📤 共有メニューから保存・送る」で、銀行・カード・ひな形・月ごとの記録をまるごと1つのファイル（.json）にします
  - 機種変更したら、新しい端末で「📂 バックアップファイルを選ぶ」で読み込みます（以前の「⬇ 書き出す」で作ったファイルも読めます）
  - 読み込む前の状態は1回分とっておくので、「↩️ 読み込む前の状態に戻す」で戻せます
  - 「📚 バックアップの履歴」に、いつ保存・読み込みしたかが残ります。14日以上していないと画面の上にお知らせが出ます
  - ファイルには銀行の名前や金額が入っているので、**GitHub にはアップロードしないでください。**
