# 荒谷町 会計帳簿アプリ

手書きの会計ノートをパソコンで付けるためのアプリです。インストール不要で、ブラウザ（Edge など）で開くだけで使えます。**インターネットにつながっていなくても動きます。**

## できること（最小版）

| 画面 | できること |
|---|---|
| 📒 帳簿 | 会計・年度を選んで1行ずつ書き込み（年月日／科目／摘要／収入金額／支払金額／差引残高／検印／備考）。残高は自動計算。「〃 前の行と同じ」ボタン。通帳残高との照合。次の年度への繰越 |
| 📊 集計 | 科目別の収入・支出合計、次年度への繰越額、月ごとの動き。印刷可 |
| 📝 候補の登録 | 科目・人名（ふりがな付き、まとめて貼り付け可）・取引先・よく使う摘要・会計の名前 |
| 💾 Excel・保存 | Excel への書き出し／読み込み、まるごとバックアップ／復元 |
| ❓ 使い方 | 1ページの操作説明 |

### 入力は「選ぶ」と「打つ」の両方ができます
- 科目・摘要は ▼ の一覧から選べます。一覧にないときは「✏ 手で入力する」を選ぶと自由に打てます。
- 新しい名前を打ったときは「一覧に追加しますか？」と聞きます。
- 「候補の登録」→「入力のしかた」で、最初から手で打つ方式にもできます。

### Excel の中身
- 会計×年度ごとに1シート（列は手書きノートと同じ）。
- **Excel でも科目・摘要の欄は ▼ で選べ、一覧にない値もそのまま打ち込めます**（入力規則のエラーを出さない設定）。
- 差引残高は計算式なので、Excel で行を書き足しても自動で計算されます。
- 「科目別集計」シート（計算式で集計）、「候補一覧」シート（プルダウンの元）、「このファイルについて」シート（アプリが読み込むときに使う表）。
- アプリで書き出した Excel は、Excel で書き足したあとでもアプリに読み込み直せます。

## 町内のパソコンで使う（ネットなしで使う方法）

1. GitHub のこのリポジトリの画面で「Code」→「Download ZIP」を押す
2. ダウンロードした ZIP を右クリック →「すべて展開」
3. 展開したフォルダの中の `aratani` フォルダを、デスクトップなど分かりやすい場所に置く
4. `aratani` フォルダの中の `index.html` をダブルクリック（Edge で開きます）
5. Edge の「お気に入り」に登録しておくと、次から簡単に開けます

> `aratani` フォルダごと USB メモリにコピーすれば、別のパソコンにも渡せます。

## ⚠️ データの保存場所（大切）

- 書き込んだ内容は、**そのパソコンのそのブラウザの中** に保存されます。GitHub やインターネットには送られません。
- 別のパソコン・別のブラウザでは見えません。ブラウザの「閲覧履歴の削除」で「Cookie とサイトデータ」を消すと消えてしまいます。
- **月に1回は「💾 Excel・保存」から Excel に書き出してください。** Excel があれば、いつでもアプリに読み込み直せます。
- 書き出した Excel やバックアップには町内の方の名前が入るので、**GitHub にはアップロードしないでください**（`.gitignore` で除外済み）。
- そのため、このプログラムの中には人名を入れていません。人名は「候補の登録」から登録してください。

## 引き継ぎ

1. 「Excel ファイルを作る」で「すべての年度」を選んで書き出し、印刷したものと一緒に次の方へ渡す
2. 次の方は Excel だけで続けても、このアプリで「Excel から読み込む」をして続けてもよい

## これから追加する予定

- 写真（レシート・領収書）からの読み取り（Claude を使える人向けのおまけ機能）
- 決算書（総会資料の形式）の Excel 出力
- 賃金集計表（1日5,000円×日数、受領印欄付き）
- 会計間の振替（1回の入力で両方の会計に記帳）、内訳（明細）、区費の徴収表・未納状況
