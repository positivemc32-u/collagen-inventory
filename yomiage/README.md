# 読み上げ・文字起こしアプリ

**文字を音声で読み上げる** ことと、**話した声を文字にする** ことができるアプリです。
パソコンでも携帯でも、ブラウザで開くだけで使えます（インストール不要）。

- URL：<https://positivemc32-u.github.io/collagen-inventory/yomiage/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます

## 🔊 読み上げ（文字 → 音声）

1. 文章を入力・貼り付け（📄 ファイルで .txt も読み込めます）。**長さの上限はありません**
2. 話し方を選ぶ：**🗼 標準語** か **🐙 関西弁**
3. 声を選ぶ（種類ごとに色分けしています）
   - 👨 **男性（大人）**：低め・ふつう・若め
   - 👩 **女性（大人）**：低め・ふつう・若め
   - 👧 **アニメの子ども役**：甘えんぼ・元気・おっとり（舌足らず）
   - 👵 **大阪のおばちゃん**：いつも関西弁で、ちょっと早口
   - 「🔊 試し聞き」で、入れた文章の最初の文を読みます。「👀 実際に読む言葉を確認する」で、関西弁などに変えた後の言葉を見られます
4. 速さを選ぶ：0.5倍〜3倍（読み上げ中に変えてもすぐ反映されます）
5. ▶ 読み上げ。今読んでいるところが黄色で表示され、**文を押すとそこから読みます**
   - ⏸ 一時停止 → ▶ つづきから ／ ⏮ ⏭ で前後の文へ ／ ⏹ で止めて文章の編集に戻ります

### 漢字の読み方について
- 漢字の読み方は、端末の読み上げエンジンが **文全体の流れ（前後の言葉）を見て** 決めています。
- 長い文章も途中でぶつ切りにせず、**必ず文の区切り（。！？・改行）で分けて** 渡すので、文の流れが保たれます。
  かっこの中（「楽しかった！」と言った。）も1つの文として扱います。
- それでも読み間違える言葉（人の名前・地名など）は、⚙️ 設定の **読み方辞書** に正しい読み方を登録できます。

### 関西弁について
- 「本当に→ほんまに」「とても→めっちゃ」「〜だ→〜や」「〜ない→〜へん」「だめ→あかん」のように、**言い回しを関西弁にして** 読みます（画面の文章は変わりません）。
- 「読んだ」（過去）のように意味が変わってしまう所は、変えずにそのまま読みます。
- イントネーション（アクセント）は端末の声のままで、関西のアクセントにはなりません。

### なめらかに話すための工夫
- 短い文はいくつかまとめて読み、次の部分を先に準備しておくので、文と文のあいだで途切れにくくなっています。
- 大人の声は、高さを変えすぎると機械っぽくなるため、控えめにしています。
- いちばん効くのは、端末に **高品質な声** を入れることです（⚙️ 設定の「もっと人の声に近づけるには」に、iPhone・Android・パソコンごとの手順があります）。

### 書いていない言葉は読みません
- 試し聞きも、入れた文章だけを使います（決まった例文は読みません）。
- 端末によって「かぎかっこ」「ほし」のように名前で読まれてしまう **かっこ・記号・絵文字** は、読む前に取りのぞきます（画面の文章はそのままです）。

### 声について
- 声は端末・ブラウザに入っている日本語の音声をもとに、**声の高さと話し方を変えて** 9種類を作っています。
- **アニメの子ども役**は、高い声で「です→でしゅ」「さん→しゃん」「スマホ→シュマホ」のように、さ行・ざ行を舌足らずに話します。
  漢字のすぐ後ろのかな（話す など）は、漢字の読み方がくずれないよう変えません。舌足らずにしたくないときは、声を選ぶ欄のチェックを外します。
- 男性の声が入っていない端末では、声を低くして男性の声にしています。
- ⚙️ 設定の「声の細かい調整」で、それぞれの声のもとにする音声と高さを変えられます。
- 一番自然なのは、パソコンの **Edge**（Microsoft Nanami / Keita の Natural 音声）や **Chrome**（Google 日本語）です。

## 🎤 文字起こし（音声 → 文字）

1. 🎤「話しはじめる」を押す（はじめにマイクの許可を聞かれたら「許可」）
2. 話すと文字になります。止めるときはもう一度押します（話の途中で間があいても聞き続けます）
3. 📋 コピー ／ 🔊 読み上げへ送る ／ 💾 保存（.txt）ができます。文字はあとから手で直せます

- 対応ブラウザ：パソコンは Chrome・Edge、iPhone は Safari、Android は Chrome（Firefox は非対応）
- 文字起こしにはインターネット接続が必要です

## データについて
- 読み方辞書や声の設定は、そのブラウザの中にだけ保存されます。
- 文章や声がこのアプリの持ち主（GitHub）に送られることはありません。
  ただし文字起こしは、ブラウザの仕組み上、Google や Apple の音声認識サービスを通ります。
