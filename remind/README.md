# リマインダーアプリ

携帯でもパソコンでも使えるリマインダーです。**声でも文字でも** 入れられます。

- URL：<https://positivemc32-u.github.io/collagen-inventory/remind/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（方法は上のフォルダの README と同じです）

## できること

| 機能 | 内容 |
|---|---|
| 🎤 音声入力 | 「明日の午後3時に歯医者」「毎週月曜の朝8時にゴミ出し」「30分後に洗濯物」のように話すと、項目・日にち・時間・くり返しが自動で入ります |
| ⌨️ 文字入力 | 項目の欄に書くだけ。文で書いたときは「✨ 文から日にち・時間を読み取る」で日にち・時間も入ります（キーボードのマイクで話した場合も同じ） |
| 📅 日にち | カレンダーで選ぶか「今日・明日・あさって・1週間後」、または「5分後・10分後・30分後・1時間後」 |
| 🕐 時間 | **くるくる回すドラム式**（指でスワイプ。パソコンはマウスホイール・ドラッグ・クリック・矢印キー） |
| 🔁 くり返し | なし／5分ごと／10分ごと／30分ごと／1時間ごと／毎日／毎週／毎月／**カスタム** |
| 🛠 カスタム | 「この日からこの日まで」「この時間からこの時間まで」「◯分ごと」を自由に組み合わせ（例：10/1〜10/7 の 9:00〜17:00 に1時間ごと） |
| 📳 バイブ | 基本は **オン**。リマインダーごとにオフにもできます |
| 🎨 色分け | 8色。設定で「赤＝仕事」のように色に名前を付けられ、一覧を色でしぼり込めます |
| 🔁 もう一回使う | 完了したものを同じ内容のまま新しい日時で作り直せます。追加画面にも前に使った項目が出ます |
| 💤 もう一度 | 鳴ったときに「5分後・10分後・30分後・1時間後」にもう一度 |
| 📅 カレンダーに入れる | 携帯のカレンダーに登録して、アプリを閉じていても確実に知らせてもらう |

### 音声で言えることの例
- 「明日の15時30分に会議の資料を送るってリマインドして」
- 「金曜日の10時半 ゴミ」「11月3日 誕生日プレゼント」「来週の水曜日の午前10時 美容院」
- 「毎日7時に起きる」「毎月25日に家賃」「5分ごとに薬」
- 「今日から3日間 午後1時から5時まで30分おきにストレッチ」

> 「3時」のように午前・午後を言わないときは、1〜6時は午後（15時など）として入ります。違うときはドラムで直してください。

## ⚠️ 知らせるしくみと注意

- このアプリは **開いている間**（裏に置いている間も多くの場合）に、画面・音・バイブ・通知で知らせます。
- アプリを完全に閉じる・電源を切る・電池の節約モードなどでは鳴らないことがあります。あとで開くと「見逃し」として出ます。
- **大事な予定は「📅 カレンダーに入れる」** を使うと、携帯のカレンダーが確実に知らせてくれます。
- **iPhone はブラウザからのバイブに対応していません。** iPhone でバイブを鳴らしたいときもカレンダー登録を使ってください。
  iPhone で通知を出すには iOS 16.4 以上で「ホーム画面に追加」したアプリから開く必要があります。
- 音声ボタンは Chrome・Edge・Safari で使えます。使えないブラウザでは、キーボードのマイクで話してください。
- データはこの端末のブラウザの中だけに保存されます（携帯とパソコンで共有はされません）。設定画面から書き出し・読み込みができます。

## ファイル構成（参考）

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面の骨組みと見た目 |
| `app.js` | 画面の表示・ボタン・時間になったら知らせる仕組み |
| `data.js` | 保存・次に鳴らす時刻の計算・カレンダー用ファイル |
| `parse.js` | 声や文から日にち・時間・くり返しを読み取る |
| `wheel.js` | くるくる回す時間のドラム |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面追加・オフライン起動・通知ボタン用 |
