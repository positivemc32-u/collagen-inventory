# 経費レシートアプリ（弥生用）

iPhone で撮ったレシートを読み取って、**やよいの青色申告に取り込める CSV** と **Excel ファイル** にするアプリです。
iPhone・Android・パソコンのどれでも、ブラウザで開くだけで使えます。

- URL：`https://（ユーザー名）.github.io/collagen-inventory/keihi/`
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます（iPhone は Safari の共有ボタン →「ホーム画面に追加」）

## 使い方

1. **📷 読み取り** で「レシートを撮る」（何枚かまとめてなら「写真から選ぶ」）
2. 自動で **日付・店名・金額（8%と10%の内訳）・登録番号** を読み取ります
3. 内容を確認して、違うところを直す
   - **勘定科目**：店名から自動で選びます。一度選んだ店は、次から同じ科目になります
   - **支払い**：事業用の現金なら「現金」、個人のお財布・カードで払ったなら「事業主借」
   - 8% と 10% が混ざったレシートは、行が2つに分かれます（「＋税率・科目を分ける」で手でも分けられます）
4. 「💾 保存」→ 次のレシートへ
5. **📋 一覧・書き出し** で月を選んで
   - **📄 弥生用CSV** … やよいの青色申告に取り込むファイル
   - **📊 Excel** … Excel で見られる一覧（＋弥生と同じ並びのシート）

携帯では共有メニューが出るので、「ファイルに保存」やメール・LINE でパソコンに送ってください。

### やよいの青色申告への取り込み方

1. 弥生用CSV（`yayoi_202610.csv` など）をパソコンに保存
2. やよいの青色申告で［帳簿・伝票］→［仕訳日記帳］を開く
3. ［ファイル］→［インポート］で CSV を選ぶ

> ⚠️ 勘定科目の名前が弥生と違うと取り込めません。弥生にない科目を使うときは、弥生側で科目を作るか、
> アプリの「⚙️ 設定」で弥生と同じ名前に直してください。
> はじめて取り込むときは、**数件だけで試して**から全部を取り込むと安心です。

## CSV の中身（弥生インポート形式）

- 文字コード Shift-JIS、見出し行なし、25項目
- 1枚のレシートが1行（8%と10%が混ざるときは複数行の伝票：2110 → 2101）
- 借方：選んだ勘定科目（税込・税区分は「課対仕入内10%」「課対仕入内軽減8%」「対象外」）
- 貸方：支払い（現金・事業主借など）
- 摘要：店名＋メモ（全角32文字まで）
- 仕訳メモ：登録番号（T＋13けた）
- 税金額は空欄（弥生が自動で計算します）

「⚙️ 設定」で **経過措置の税区分** をオンにすると、登録番号のないレシートは
「課対仕入内10%区80%」（2026年10月からは「区50%」）で書き出します。
本則課税の人向けです。免税事業者・簡易課税・2割特例の人はオフのままで大丈夫です。

## 読み取りについて

- 文字の読み取りは **携帯・パソコンの中で** 行います（写真をどこかのサーバーに送ることはありません）
- 初回だけ、文字認識のデータ（日本語、数MB）をインターネットから取り込むので少し時間がかかります。
  Wi-Fi のあるところで1回使っておくと安心です
- しわ・かすれ・暗い写真は読み間違えることがあります。**保存の前に必ず金額と日付を確認**してください
- 読み取りに時間がかかるときは「やめて手で入力する」を押せます

## データの保存場所

- レシートの内容と写真は **この端末のブラウザの中だけ** に保存されます（GitHub には保存されません）
- 別の携帯・別のブラウザでは見えません。機種変更の前は「⚙️ 設定」→「バックアップを書き出す」
- 書き出した CSV・Excel・バックアップには経費の情報が入っています。**GitHub にはアップロードしないでください**

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 画面の表示とボタン操作 |
| `data.js` | 勘定科目・税区分・保存 |
| `ocr.js` | 写真の読み取りと、日付・金額などの推測 |
| `export.js` | 弥生CSV（Shift-JIS）と Excel の作成 |
| `vendor/` | 文字認識（Tesseract.js 5.1.1）と Excel 作成（SheetJS 0.18.5）のライブラリ。どちらも Apache-2.0 |
