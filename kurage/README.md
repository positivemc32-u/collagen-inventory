# クラゲのニューストピック

携帯でもパソコンでも使える、ニュースと占いのアプリです。水色のクラゲのキャラクターが案内します。

- URL：<https://positivemc32-u.github.io/collagen-inventory/kurage/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます

## できること

| 機能 | 内容 |
|---|---|
| 📑 目次（インデックス） | 項目の一覧を番号つきで表示。**≡ をつまんで上下にドラッグ**すると順番（優先順位）を変えられます（指でもマウスでも） |
| ＋ 項目を足す | 好きな項目を足せます。足した項目には「✏️ 書く」で自分でニュースやメモを入れられます |
| 🗾🌍 発信地 | すべての記事に「日本発信」か「世界発信」を表示。日本発信の記事には「🌍 世界から見ると」（世界でどう見られているか・世界の似たもの）つき |
| 🔊 読み上げ | **記事のどこをタップしても、その記事から再生**して、そのまま先へ続けます。▶ でいちばん最初から |
| ▶ 再生の順番 | 目次の順に再生します。≡ で項目を並べかえると、再生の順番も変わります |
| 🎵 ほかの音楽を止める | 読み上げを始めると、Apple Music などほかのアプリの音楽を止めて、ニュースだけが流れるようにしています（ロック画面やイヤホンのボタンでも一時停止・次へができます） |
| 🔇 ミュート | 読んでいる場所を覚えたまま音だけ止めます。もう一度押すと続きから |
| 🎙 声 | 「落ち着いた男性」「落ち着いた女性」から選べます。⚙️ 設定の「声をくわしく選ぶ」で端末の声を直接選べます（⭐ が聞きやすい高品質な声） |
| 🐢 速さ | 0.5倍〜2倍 |
| 🖼 ニュース画像 | 記事ごとに文字テロップと、動く水色のクラゲが出ます |
| 🪼 クラゲ | 画面の端からときどき顔を出します（押すとしゃべります。設定で消せます） |

## 最初から入っている項目

各項目 3記事。いま話題になっている新しい情報を選んでいます（毎朝その日の新しい情報で更新）。

1. 🗞 今日の話題ニュース
2. ☀️ 今日の天気（「⚙️ 設定」の「☀️ 天気の地域」で市町村まで選べます。天気は無料の天気サービス Open-Meteo から**毎回自動**で取ってきます。地域は端末の中だけに保存）
3. 🏯 石川県ニュース
4. ♨️ 地元のニュース（「⚙️ 設定」で地域を入れると、「🤖 Claudeで更新」で取ってきます。地域は端末の中だけに保存）
5. 🧸 子育て
6. 📰 子ども新聞から（子ども向けの新聞やニュースで取り上げられた話題）
7. ⚾ スポーツ（くわしくない人にもわかるよう、選手やチーム、競技の特徴を短く説明）
8. 🎵 音楽
9. 🔬 サイエンス
10. 🫀 人体解剖学（体のしくみの研究やニュースと、体の豆知識）
11. 🌿 植物療法（フィトテラピー）
12. 🌸 アロマ
13. 💄 シナリー（シナリー化粧品の新製品・使い方の工夫・成分の話。公式サイトなどから）
14. 🏠 不動産・賃貸オーナーの学び
15. 💊 分子栄養学・オーソモレキュラー
16. 🔯 スピリチュアル
17. 👻 都市伝説（真偽がわかっているものはそれも書きます）
18. 🍁 四季と暦 … 今の二十四節気・七十二候と、旬・行事は**毎日自動**。季節のニュースを1件
19. 🔮 今日の占い・運気（設定に入れた人の分だけ。**毎日自動で計算**）

> 占いの生年月日・時間・場所は「⚙️ 設定」か、占いの項目の「🎂 生年月日を変える」で入れます。
> 入れた内容はこの端末のブラウザの中にだけ保存され、GitHub には入りません。

## 冥鳴ひまりの声で読む（無料・毎朝自動）

ニュースが更新されると、GitHub Actions（`.github/workflows/pages.yml`）が VOICEVOX ENGINE を動かして、
その日の記事を「VOICEVOX:冥鳴ひまり」の声で音声にし、サイトと一緒に公開します。

- 料金はかかりません。アプリを使う人はだれでも、設定なしでこの声で聞けます
- 音声はリポジトリには入れず、公開サイトにだけ置きます。毎日入れ替わるので、古い日の音声は残りません（1日 約5MB）
- ニュースの更新から音声ができるまで、20分ほどかかります。それまでは端末の声で読みます
- 天気・占い・地元のニュース・Claude で更新した記事など、端末ごとにちがう記事は、さくらのAI Engine（設定していれば）か端末の声で読みます
- ⚙️ 設定の「作っておいた冥鳴ひまりの声で読む」を外すと、使わなくなります
- 最初に1回だけ、GitHub の Settings → Pages → Build and deployment の Source を「GitHub Actions」にしてください
- 作り方：`kurage/tools/make-audio.mjs`（読み上げる文章はアプリと同じ `kurage/speech.js` で作ります）

## VOICEVOX の声で読む（さくらのAI Engine）

⚙️ 設定の「🎙 VOICEVOX の声で読む」で、さくらインターネットの「さくらのAI Engine」の音声合成を使えます（おすすめの声：冥鳴ひまり）。

1. さくらのクラウドのコントロールパネルで、さくらのAI Engine のアカウントトークンを発行し、音声合成モデルの利用規約に同意しておきます
2. アプリの ⚙️ 設定でトークンを入れ、「🔊 VOICEVOX の声を試し聞き」を押します（音声モデル名は最初から「himari」を入れてあります。コントロールパネルの表示と違うときは直してください）
3. 聞こえたら「VOICEVOX の声で読む」にチェックを入れます

- トークンはこの端末のブラウザの中だけに保存し、さくらインターネットの API にだけ送ります
- 利用料はさくらのAI Engine の料金になります
- うまく使えないとき（トークンの間違い、通信できないなど）は、端末の声で読みます
- クレジット：VOICEVOX:冥鳴ひまり

## 声をもっと聞きやすくするには

- **iPhone**：「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」で、「拡張」や「プレミアム」の声（Siri の声も）をダウンロードし、アプリの ⚙️ 設定「声をくわしく選ぶ」で選んでください。いちばん効果があります
- **パソコン**：Microsoft Edge で開くと、自然な「Nanami」「Keita」の声が使えます

> iPhone で Apple Music が止まらないときは、iOS を最新にして、ホーム画面に追加したアプリから開いてみてください。

## ニュースを毎日新しくするには

ニュースの項目（1〜7・10〜12と足した項目）は、作った日（2026年10月26日）に調べた内容が入っています。
毎日の新しいニュースにするには、次のどちらかです。

- **アプリの中で更新**：⚙️ 設定に Anthropic の APIキーを入れて「🤖 全部の項目を今日のニュースに更新」を押すと、Claude がインターネットで調べて入れ替えます（APIの利用料がかかります。キーはこの端末の中だけに保存されます）
- **このファイルを更新**：`kurage/news.js` の中身をその日のニュースに書き換えて main に入れる

占い・節気・旬は、インターネットがなくても毎日自動で今日の内容になります。

## 注意

- 読み上げの声は、端末に入っている日本語の声を使います。男性の声が入っていない端末では、女性の声を低くして男性の声にします。
- 書いた記事・項目の順番・設定は、この端末のブラウザの中にだけ保存されます。
- 占いは楽しみとしてお使いください。
