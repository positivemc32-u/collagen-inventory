# クラゲのニューストピック

携帯でもパソコンでも使える、ニュースと占いのアプリです。水色のクラゲのキャラクターが案内します。

- URL：<https://positivemc32-u.github.io/collagen-inventory/kurage/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます

## できること

| 機能 | 内容 |
|---|---|
| 📑 目次（インデックス） | 項目の一覧を番号つきで表示。**≡ をつまんで上下にドラッグ**すると順番（優先順位）を変えられます（指でもマウスでも） |
| ＋ 項目を足す | 好きな項目を足せます。足した項目には「✏️ 書く」で自分でニュースやメモを入れられます |
| 🎯 ターゲット | 各項目に **30代女性・40代女性・50代女性・30代男性・40代男性・50代男性 へ1記事ずつ（6記事）**、この順に並びます。端的に、話のネタつき |
| 🗾🌍 発信地 | すべての記事に「日本発信」か「世界発信」を表示。日本発信の記事には「🌍 世界から見ると」（世界でどう見られているか・世界の似たもの）つき |
| 🔊 読み上げ | **記事のどこをタップしても、その記事から再生**して、そのまま先へ続けます。▶ でいちばん最初から |
| ▶ 再生の順番 | 最初は **30代女性 → 40代女性 → 50代女性 → 30代男性 → 40代男性 → 50代男性** の順（全部の項目から）。⚙️ 設定で並べ替えたり、「目次の順」に変えたりできます |
| 🎵 ほかの音楽を止める | 読み上げを始めると、Apple Music などほかのアプリの音楽を止めて、ニュースだけが流れるようにしています（ロック画面やイヤホンのボタンでも一時停止・次へができます） |
| 🔇 ミュート | 読んでいる場所を覚えたまま音だけ止めます。もう一度押すと続きから |
| 🎙 声 | 「落ち着いた男性」「落ち着いた女性」から選べます。⚙️ 設定の「声をくわしく選ぶ」で端末の声を直接選べます（⭐ が聞きやすい高品質な声） |
| 🐢 速さ | 0.5倍〜2倍 |
| 🖼 ニュース画像 | 記事ごとに文字テロップと、動く水色のクラゲが出ます |
| 🪼 クラゲ | 画面の端からときどき顔を出します（押すとしゃべります。設定で消せます） |

## 最初から入っている項目

各項目 6記事（30代女性・40代女性・50代女性・30代男性・40代男性・50代男性 に1つずつ）です。占いは、⚙️ 設定に入れた人（あなた）の分だけ出ます。

1. 🗞 今日の話題ニュース
2. 🌿 植物療法（フィトテラピー）
3. 🌸 アロマ
4. ⚾ スポーツ業界
5. 🏠 不動産・賃貸オーナーの学び
6. 🎵 音楽
7. 🍁 日本の四季（月ごとの旬と行事は毎日自動）
8. 🌗 二十四節気・七十二候（**毎日自動で計算**）
9. 🔮 今日の占い・運気（**毎日自動で計算**）… 総合運・西洋占星術（太陽・月・アセンダント）・数秘術・九星気学と風水・クラゲの直感リーディング
10. 🔯 スピリチュアル（世界・日本）… 世界と日本の「今話題のもの」と、季節の行事・言い伝えなど
11. 👻 都市伝説（世界・日本）… 世界と日本の「今話題のもの」と、定番の話・「実は本当だった話」。真偽がわかっているものはそれも書きます
12. 💊 分子栄養学・オーソモレキュラー

> 占いの生年月日・時間・場所は「⚙️ 設定」か、占いの項目の「🎂 生年月日を変える」で変えられます。
> 最初は空っぽです。入れるまでは占いの代わりに「🎂 生年月日を入れると、毎日の占いが出ます」と表示されます。時間がわからないときは「時間はわからない」にチェック。
> 入れた生年月日は **この端末のブラウザの中だけ** に保存されます。個人情報はプログラム（app.js など）には書かないでください（GitHub で公開されています）。

## 声をもっと聞きやすくするには

- **iPhone**：「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」で、「拡張」や「プレミアム」の声（Siri の声も）をダウンロードし、アプリの ⚙️ 設定「声をくわしく選ぶ」で選んでください。いちばん効果があります
- **パソコン**：Microsoft Edge で開くと、自然な「Nanami」「Keita」の声が使えます

> iPhone で Apple Music が止まらないときは、iOS を最新にして、ホーム画面に追加したアプリから開いてみてください。

## ニュースを毎日新しくするには

ニュースの項目（1〜7・10〜12と足した項目）は、作った日（2026年10月26日）に調べた内容が入っています。
毎日の新しいニュースにするには、次のどちらかです。

- **アプリの中で更新**：⚙️ 設定に Anthropic の APIキーを入れて「🤖 全部の項目を今日のニュースに更新」を押すと、Claude がインターネットで調べて入れ替えます（APIの利用料がかかります。キーはこの端末の中だけに保存されます）
- **このファイルを更新**：`kurage/news.js` の中身をその日のニュースに書き換えて main に入れる

占い・節気・旬は、インターネットがなくても毎日自動で今日の内容になります。

## 注意

- 読み上げの声は、端末に入っている日本語の声を使います。男性の声が入っていない端末では、女性の声を低くして男性の声にします。
- 書いた記事・項目の順番・設定は、この端末のブラウザの中にだけ保存されます。
- 占いは楽しみとしてお使いください。
