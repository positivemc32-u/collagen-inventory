# クラゲのニューストピック

携帯でもパソコンでも使える、ニュースと占いのアプリです。水色のクラゲのキャラクターが案内します。

- URL：<https://positivemc32-u.github.io/collagen-inventory/kurage/>
  （コラーゲン管理アプリと同じ GitHub Pages の中にあります。main に取り込めば自動で公開されます）
- 携帯ではホーム画面に追加すると、アプリのように使えます

## できること

| 機能 | 内容 |
|---|---|
| 📑 目次（インデックス） | 項目の一覧を番号つきで表示。**≡ をつまんで上下にドラッグ**すると順番（優先順位）を変えられます（指でもマウスでも） |
| ＋ 項目を足す | 好きな項目を足せます。足した項目には「✏️ 書く」で自分でニュースやメモを入れられます |
| 🔊 読み上げ | ▶ で上から順に全部読みます。項目ごと・記事ごとに「ここから読む」もできます |
| 🔇 ミュート | 読んでいる場所を覚えたまま音だけ止めます。もう一度押すと続きから |
| 🎙 声 | 「落ち着いた男性」「落ち着いた女性」から選べます |
| 🐢 速さ | 0.5倍〜2倍 |
| 🖼 ニュース画像 | 記事ごとに文字テロップと、動く水色のクラゲが出ます |
| 🪼 クラゲ | 画面の端からときどき顔を出します（押すとしゃべります。設定で消せます） |

## ニュースを毎日新しくするには

ニュースの項目（1〜7・10と足した項目）は、作った日（2026年10月26日）に調べた内容が入っています。
毎日の新しいニュースにするには、次のどちらかです。

- **アプリの中で更新**：⚙️ 設定に Anthropic の APIキーを入れて「🤖 全部の項目を今日のニュースに更新」を押すと、Claude がインターネットで調べて入れ替えます（APIの利用料がかかります。キーはこの端末の中だけに保存されます）
- **このファイルを更新**：`kurage/news.js` の中身をその日のニュースに書き換えて main に入れる

占い・節気・旬は、インターネットがなくても毎日自動で今日の内容になります。

## 注意

- 読み上げの声は、端末に入っている日本語の声を使います。男性の声が入っていない端末では、女性の声を低くして男性の声にします。
- 書いた記事・項目の順番・設定は、この端末のブラウザの中にだけ保存されます。
- 占いは楽しみとしてお使いください。
