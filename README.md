# コラーゲン顧客・在庫管理アプリ

ザクロ味・ゆず味のコラーゲン商品について、**顧客情報・毎月の発送記録・在庫** をスマホで管理するアプリです。
インストール不要で、スマホのブラウザで開いて「ホーム画面に追加」すればアプリのように使えます。

---

## ⚠️ はじめに必ず読んでください：データの保存場所

- 顧客情報などのデータは **このスマホのブラウザの中だけ** に保存されます。
- **GitHub やインターネット上には一切保存・送信されません。** GitHub に置いてあるのは「アプリの画面の仕組み（プログラム）」だけです。
- そのため、次のときはデータが消えたり見えなくなったりします。
  - ブラウザの「履歴とWebサイトデータを消去」をしたとき
  - 別のスマホ・別のブラウザ（例：Safari と Chrome）で開いたとき
  - 機種変更したとき
- **定期的に「バックアップ」画面から CSV を書き出して保存してください。**
  （14日以上バックアップしていないと、画面の上にお知らせが出ます）
- 書き出した CSV には個人情報が入っています。**GitHub には絶対にアップロードしないでください。**
  念のため `.gitignore` という設定ファイルで、CSV ファイルが GitHub に入らないようにしてあります。

## できること

| 画面 | できること |
|---|---|
| 📦 発送リスト | その月に発送する人だけを表示（毎月の人／その月が発送月の隔月の人／その月に追加した単発の人）。名前検索、「未対応だけ」「手渡しだけ」などの絞り込み。状況・入金をその場で切り替え。伝票・伝票番号・メモの記録。◀ ▶ で過去の月の記録も見られます |
| 📋 一覧 | すべてのお客様の記録を1つの表で表示（年月・お名前・区分・ザクロの数・ゆずの数・発送・伝票・入金）。年月とお名前で絞り込み、「未発送だけ」「未入金だけ」「伝票未送付」の絞り込みもできます |
| 👤 顧客 | 顧客の登録・編集・削除。ザクロとゆずの個数をそれぞれ入力できます。隔月の人は「✅ 10月は発送月」「💤 10月はお休み（次は11月）」がひと目でわかります |
| 📊 在庫 | 味ごとに月初在庫・月の途中の入荷を記録。発送済み・手渡し済みの個数を自動で数えて月末の残りを表示。在庫が足りないと ⚠️ 警告 |
| 💾 バックアップ | CSV の書き出し（バックアップ）と読み込み（復元） |

## 公開のしかた（GitHub Pages）※最初に1回だけ

GitHub Pages は、GitHub に置いたファイルを無料でWebサイトとして公開できる機能です。

### 1. プログラムを main ブランチに入れる

このアプリのファイルは `claude/collagen-customer-inventory-app-0a0vz8` というブランチ（作業用の枝）に入っています。
GitHub のリポジトリ画面で「Pull requests」→ 該当のプルリクエストを開き、**「Merge pull request」→「Confirm merge」** を押して main に取り込んでください。
（プルリクエストがない場合は「Compare & pull request」ボタンから作成できます）

### 2. GitHub Pages を有効にする

1. GitHub でこのリポジトリ（`collagen-inventory`）を開く
2. 上のメニューの **⚙ Settings（設定）** を押す
   （スマホの場合は画面が狭いので、ブラウザのメニューから「PC版サイトを表示」にすると操作しやすいです）
3. 左のメニューから **Pages** を押す
4. 「Build and deployment」の **Source** を **「Deploy from a branch」** にする
5. **Branch** を **`main`**、フォルダを **`/ (root)`** にして **Save** を押す
6. 1〜3分待ってページを再読み込みすると、上の方に
   `Your site is live at https://（ユーザー名）.github.io/collagen-inventory/`
   と表示されます。これがアプリのURLです。

> 💡 **リポジトリが Private（非公開）の場合**：GitHub の無料プランでは、Private リポジトリで GitHub Pages は使えません。
> Settings → 一番下の「Danger Zone」→「Change visibility」で **Public（公開）** にしてください。
> 公開されるのはアプリのプログラムだけで、**顧客データはスマホの中にしかないので公開されません。**
> （検索エンジンに載らないよう、ページには「検索に表示しない」設定も入れてあります）

### 3. スマホのホーム画面に追加する

上のURLをスマホで開いてから：

- **iPhone（Safari）**：画面下の **共有ボタン（□に↑）** →「**ホーム画面に追加**」→「追加」
- **Android（Chrome）**：右上の **︙** →「**ホーム画面に追加**」（または「アプリをインストール」）

ホーム画面のアイコンから開くと、アプリのように全画面で使えます。一度開けば電波がなくても起動できます。

> ⚠️ iPhone では「Safari で開いたとき」と「ホーム画面のアイコンから開いたとき」で **データが別々** になることがあります。
> どちらか一方（おすすめはホーム画面のアイコン）に決めて使ってください。

## 使い方

どの画面でも、上のほうに **「2026年10月」のように大きく年月** が出ています。◀ ▶ で月を切り替え、年月の部分を押すと今月に戻ります（一覧画面では「全期間」に戻ります）。
今月以外を見ているときは、年月の色がオレンジになります。

### ① 顧客を登録する
「👤 顧客」→「＋ 新しい顧客を登録」から入力して「保存」。

- **ザクロ（個）・ゆず（個）**：それぞれの個数を入れます。両方頼む人は両方に、片方だけの人はもう片方を **0** にします
- **定期便の種類**
  - 毎月：開始月から毎月、発送リストに出ます
  - 隔月：開始月から **2か月ごと** に発送リストに出ます（例：開始月が9月なら 9月・11月・1月…）。入力画面に発送月が表示されるので確認できます
  - 単発：自動では出ません。発送リストの「＋ 単発の人を追加」で、注文があった月だけ追加します
- **受け渡し方法**：直送／手渡し
- **配送時間指定**（クロネコヤマト）：指定なし／午前中／14〜16時／16〜18時／18〜20時／19〜21時
- **休止中**：オンにすると発送リストに出なくなります（データは残ります）
- 住所・電話番号は空欄でもOK。メモは自由に書けます

### ② 毎月の発送作業
「📦 発送リスト」を開くと、今月発送する人だけが出ます。

- カードの **状況**（未対応／発送済み／手渡し済み）と **入金**（未入金／入金済み）は、その場で切り替えられます
- 名前の部分をタップすると詳細が開き、**伝票（未送付／送付済み）・伝票番号・メモ**、その月だけのザクロ・ゆずの個数の変更ができます
- 上の「未対応だけ」「手渡しだけ」などのボタンで絞り込み、検索欄で名前検索ができます
- 上部の ◀ ▶ で月を切り替えると過去の記録が見られます。真ん中の月の表示を押すと今月に戻ります
- 記録は月ごとに別々に残るので、顧客情報を変えても過去の記録は変わりません

### ③ 一覧でまとめて確認する
「📋 一覧」を開くと、すべてのお客様の記録が月ごとに表になって並びます（新しい月が上）。

- 「年月で絞り込み」で特定の月だけ、検索欄でお名前だけに絞れます。上の ◀ ▶ でも月を選べます
- 「未発送だけ」「未入金だけ」で、送り忘れや入金漏れを探せます
- 表は横にスクロールできます。行を押すと、その月の記録を編集できます
- まだ何も入力していない月の人も「未対応・未入金」として並びます（今月まで）

### ④ 在庫を管理する
「📊 在庫」で：

1. 月の初めに、味ごとの **月初在庫** を入力（前月の記録があれば「月初在庫にする」ボタンで引き継げます）
2. 商品が届いたら「＋ 入荷を記録」
3. 発送リストで「発送済み」「手渡し済み」にした個数が、**ザクロ・ゆず別々に** 自動で引かれ、**月末の残り** が表示されます
4. 未対応の人に送る分より在庫が少ないと、⚠️ の警告が出ます

### ⑤ バックアップ（週に1回くらいがおすすめ）
「💾 バックアップ」→「📥 CSVをダウンロード」

- iPhone の場合は「📤 共有メニューから保存」→「"ファイル"に保存」や、自分だけのクラウド（iCloud Drive、Google ドライブなど）に保存すると便利です
- CSV は Excel や Numbers、Google スプレッドシートでも開けます

### ⑥ 復元・機種変更
1. 古いスマホで CSV を書き出す
2. 新しいスマホでアプリを開き「💾 バックアップ」→「📂 CSVファイルを選ぶ」
3. 確認画面で「OK」を押すと、データが CSV の内容に置き換わります

> CSV を Excel などで編集した場合も読み込めますが、1列目の「種別」と各列の名前は変えないでください。
> 以前のバージョンで書き出した CSV（「味」「個数」の列があるもの）も、そのまま読み込めます。

## よくある質問

**Q. データが消えてしまった**
A. ブラウザのデータ消去や、別のブラウザで開いている可能性があります。最後に書き出した CSV を読み込めば元に戻せます。

**Q. 隔月の人が今月出てこない**
A. 開始月から数えて2か月ごとに表示されます。顧客の編集画面で「開始月」を確認してください。今月だけ臨時で送る場合は、発送リストの「＋ 単発の人を追加」→「その他」から追加できます。

**Q. アプリを更新したら、前に入力したデータはどうなる？**
A. そのまま残ります。以前の「味＋個数」の形式は、自動で「ザクロ◯個・ゆず◯個」の形に直されます（例：ゆず2個 → ザクロ0個・ゆず2個）。「イレギュラー」は「単発」という名前に変わります。念のため、直す前のデータもスマホの中に控えとして残しています。

**Q. アプリを更新したのに画面が変わらない**
A. アプリを一度完全に閉じてから開き直してください。それでも変わらない場合は、少し時間をおいてから再度開いてください。

**Q. パソコンとスマホでデータを共有したい**
A. このアプリは個人情報を守るため、データを端末の外に送りません。片方で CSV を書き出し、もう片方で読み込んでください。
